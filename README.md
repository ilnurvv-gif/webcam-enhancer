# Webcam Enhancer

Улучшает картинку с веб-камеры в реальном времени и отдаёт её в виртуальную
камеру — её можно выбрать в Zoom, Telegram, Discord, Teams, Google Meet и т.д.

## Что улучшается

| Ползунок     | Что делает |
|--------------|------------|
| Brightness   | Яркость (100 — без изменений) |
| Contrast     | Контраст, % |
| Gamma        | Больше 100 — светлее тени, лицо в полумраке видно лучше |
| Auto light   | Автовыравнивание освещения (вытягивает тени, убирает пересвет) |
| White bal    | Автобаланс белого (убирает жёлтый/синий оттенок от ламп) |
| Denoise      | Шумоподавление — главное против «зерна» в тёмной комнате |
| Sharpen      | Резкость |
| Saturation   | Насыщенность цвета, % |
| Mirror       | Зеркальное отображение |

Также программа сама включает у камеры **максимальное разрешение (1080p, MJPG)** —
многие камеры по умолчанию работают в 640x480, и уже одно это сильно
улучшает картинку.

## Установка

1. Установите **OBS Studio** — https://obsproject.com
   (нужен только его драйвер «OBS Virtual Camera», сам OBS запускать не надо).
2. Скачайте `WebcamEnhancer.exe` (см. «Сборка через GitHub» ниже) и запустите.
3. В Zoom / Telegram / Discord выберите камеру **OBS Virtual Camera**.

Окно программы должно оставаться открытым (можно свернуть).

## Клавиши (в окне предпросмотра)

- **C** — сравнение «до | после»
- **S** — настройки драйвера камеры (экспозиция, фокус, антимерцание 50 Гц и др.)
- **V** — включить/выключить виртуальную камеру
- **R** — сбросить настройки
- **Q / Esc** — выход (настройки сохраняются в `webcam_enhancer.json` рядом с exe)

## Параметры запуска

```
WebcamEnhancer.exe --camera 1              # другая камера
WebcamEnhancer.exe --width 1280 --height 720   # если компьютер слабый и FPS низкий
```

## Сборка через GitHub

1. Создайте репозиторий и загрузите в него все файлы (вместе с папкой `.github`).
2. Откройте вкладку **Actions** → сборка запустится сама.
3. Через пару минут откройте завершённую сборку → внизу **Artifacts** →
   скачайте `WebcamEnhancer`.

## Запуск без сборки (если установлен Python)

```
pip install -r requirements.txt
python webcam_enhancer.py
```

## Советы

- Если картинка мерцает — нажмите **S** и выставьте «Powerline frequency» = 50 Hz.
- Самое заметное улучшение даёт свет: лампа или окно **перед** лицом, а не за спиной.
- Программа не может добавить деталей, которых камера не сняла, но убирает шум,
  исправляет цвет и свет — то, из-за чего веб-камеры выглядят плохо чаще всего.
